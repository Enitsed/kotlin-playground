🚀 HOW TO GET STARTED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Choose Your Starting Point

Option A - Fast Start (Ktor):
$ cd ktor-api-server
$ ./gradlew run
✓ Server runs in ~10 seconds
✓ Test with: curl http://localhost:8080/api/v1/users

Option B - Full Setup (Spring Boot):
$ cd spring-boot-api-server
$ docker-compose up -d    # Start MySQL
$ ./gradlew bootRun
✓ Server runs with database
✓ Swagger UI at: http://localhost:8080/swagger-ui.html

Step 2: Test the APIs
$ curl http://localhost:8080/api/v1/users
$ curl -X POST http://localhost:8080/api/v1/users \
    -H "Content-Type: application/json" \
    -d '{"name":"Test","email":"test@example.com","age":25}'

Step 3: Explore the Code
├─ Read the single Application.kt for Ktor
├─ Study the 7-file architecture for Spring Boot
├─ Compare the different approaches
└─ Understand how concepts map from Express/NestJS

Step 4: Modify and Experiment
├─ Add a new endpoint
├─ Change validation rules
├─ Switch databases
└─ Add authentication

All these Kotlin features are demonstrated:

1. Data Classes
   data class User(val id: Long, val name: String)

2. Coroutines
   suspend fun fetchUser(): User

3. Extension Functions
   fun String.isValidEmail(): Boolean

4. Sealed Classes
   sealed class Result<T>

5. Scope Functions
   user.apply { name = "Updated" }

6. Type Safety
   val users: List<User> = ...

7. Null Safety
   val email: String?

8. Lambda Expressions
   users.filter { it.age > 30 }

9. Collections
   users.map { it.toDTO() }

10. Annotations
    @RestController, @Entity, @Service
